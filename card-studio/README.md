# 凡人 · 三场景典藏

`npm ci && npm test && npm run build` 重建三张卡的 `app.bundle.js` 并更新静态资源版本。
在仓库根目录运行 `python3 -m http.server 4176 --bind 127.0.0.1`，打开 `/cards/`。

点击“旋转入画”或轻点卡片：音频开始播放，卡片围绕接近正常中轴的位置旋转，轴线只做小幅偏摆，中心保持在原位，减速时带少量余晃，再停在原有正面视角。暂停、缓冲与拖动音频进度条都会同步到卡片；音乐在定格后继续。拖动卡面、翻面、复位和自动赏卡会结束本次入画。页面隐藏时暂停音乐；减少动态效果系统设置下改用短距离转动。

旋转使用 `HTMLAudioElement.currentTime`，按音频进度采样四元数姿态。每次起转固定一次随机初始冲量，小幅摆轴和阻尼保持连续；暂停与跳转不会重新随机。动作是带轻微晃动的自旋编排，并非刚体接触物理仿真。可以设置音频起点与入画时长，也可以选择设备上的音频；本地音频不上传、不写入持久缓存，刷新恢复随附小样。

## 配乐来源

`quiet-promise.wav` 是本项目的临时合成氛围小样，**不是《凡人修仙传》的原曲或改编录音**。由 `python3 scripts/compose-demo.py` 使用正弦合成生成，不含第三方采样。8 秒处的和弦与默认定格位置对应；这是固定编排，不是自动节拍识别。

原场景配乐的线索是 [fisher--- 的第 136 集还阳术护法去人声投稿](https://www.bilibili.com/video/BV1UaZeYwEkZ/)；尚未确认原曲曲名和可直接用于同步播放的音源，未将投稿音轨打包或转载。投稿页出现的《One Destiny To Follow》标签不足以证实其为原场景配乐。

## 验证

Node 测试覆盖任意姿态起转与重播、终点连续性、轴线倾斜范围和中心固定、音频采样确定性、卡片边界、减少动态效果与短音频裁剪。发布前另做浏览器真实播放、暂停、重播、翻面与移动布局验证。浏览器可能要求一次明确点击才允许声音；播放失败会给出提示。

## 场景顺序与默认运镜

1. 紫灵 · 烟火人间：向画内推进，副标题“韩大哥，那一年的烟花最好看”。
2. 元瑶 · 护道还魂：从左到右，保留“你只管做你想做的”。
3. 南宫 · 月满相逢：拉远展开视野；参考图精确集数尚未核实，来源说明保留在藏品档案。

默认运镜 16 秒一程、32 秒平滑往返；点击旋转会结束自动运镜。`scene-motion.mjs` 管理运镜，`scene-effects.mjs` 管理阵光、烟花和月光；元瑶保留原有光丝着色。配置和四层素材位于 `cards/<id>/`，全站使用相对链接，支持项目型 GitHub Pages。

运镜幅度修订：默认上下/左右移动增至原来的约 1.67 倍，推进/拉远也增大约 1.6–1.7 倍，并增加必要的画面预放大以保留边缘余量。节奏仍为 16 秒一程。
